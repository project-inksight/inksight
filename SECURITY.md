# Security Policy

## Local-First Privacy by Design
**Inksight** runs 100% locally on your own hardware with zero cloud relays, zero external telemetry, and zero third-party account requirements.

- Never port-forward ports `3001`, `1984`, or `8554` directly to the public internet.
- For remote mobile viewing outside your home or office Wi-Fi, always use a private encrypted mesh VPN such as **Tailscale** or **WireGuard**.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.0.x` | ✅ Yes |

## Reporting a Vulnerability
If you discover a security vulnerability in Inksight, please open a GitHub Security Advisory via the repository's **Security → Report a vulnerability** tab rather than posting exploit details in a public issue.
